# MuJoCo 图像与运动历史学习预测

本页路径相对于仓库根目录。命令示例从仓库根目录的 CMD 开始；第一次 cd 进入本阶段目录。依赖安装见[仓库说明](../README.md)。

这个版本已实际完成 MuJoCo 数据采集、三个神经网络训练、独立测试、分布外对照和新物理运行中的流式预测。包含五个环节：采集图像与状态、构造历史序列、训练图像与历史模型、在线更新潜在状态、独立测试与消融。当前结果主要依赖运动历史，尚不能把融合模型的改善归因于图像。

## 开始运行

打开 `mujoco_learned_ready`，双击 `run_demo.cmd`，可以直接使用已有训练权重运行 MuJoCo 三维窗口和 Matplotlib 在线预测显示，无需先重训。未重新采集时，演示会自动读取随仓库提供的 `demo_assets/manifest.json`。演示重新运行物理仿真，实时产生观测与 RGB，不是只播放已保存的预测曲线；输入仍是预先规定的命令，没有神经网络轨迹控制器。

双击 `run_all.cmd` 会依次执行采集、重新训练和测试。默认训练 40 个 epoch，训练随机种子为 0。若要保留仓库随附的参考结果，请使用下文的自定义目录参数。CPU 训练和相机采集可能耗时较长，请查看终端中的进度与损失。

启动器优先使用上一级目录的 `.venv\Scripts\python.exe`，找不到时调用命令行中的 `python`。本项目使用 PyTorch CPU、MuJoCo、NumPy 等现有环境；启动器不会安装依赖或修改系统设置。相机采集采用离屏渲染，仍需要可用的 OpenGL 图形环境。

在已经激活原虚拟环境的 CMD 中，也可以运行：

```cmd
cd /d mujoco_learned_ready
python demo.py
```

只执行无窗口流式演示，或重新运行完整流程：

```cmd
python demo.py --headless
python pipeline.py all
```

不指定子命令时，默认执行 `all`。分别运行各阶段：

```cmd
python pipeline.py collect
python pipeline.py train --epochs 40 --seed 0
python pipeline.py evaluate
```

`train_only.cmd` 只训练，要求先完成采集；`evaluate.cmd` 使用已有数据和权重执行测试，不重新训练。

| 参数 | 作用 |
|---|---|
| `--data-dir PATH` | 数据目录，默认项目内的 `data` |
| `--output-dir PATH` | 模型与结果目录，默认 `results\trained` |
| `--epochs 40` | 训练轮数，默认 40 |
| `--seed 0` | 训练随机种子，默认 0 |

使用自定义目录时，各阶段必须指向同一组数据和模型，例如：

```cmd
python pipeline.py collect --data-dir data_test --output-dir results_test
python pipeline.py train --data-dir data_test --output-dir results_test --epochs 40 --seed 0
python pipeline.py evaluate --data-dir data_test --output-dir results_test
```

## 数据与相机

MuJoCo 物理步长为 0.002 秒，即 500 Hz；状态和 RGB 数据按 0.1 秒间隔采样，即 10 Hz。已采集 84 个 episode：48 个训练、12 个验证、12 个独立测试、12 个分布外测试。每个 episode 保存 121 张 64×64 RGB，共 10,164 帧，并保存状态、输入等 NPZ 日志。

当前相机是轮地接触附近的理想向下相机，渲染时隐藏机器人几何体，以便观察接触区域。它不能提前看见前方路况，也不能视作真实安装相机可以直接复现的视角；实物还需要重新设计相机安装、遮挡与标定。

数据按完整 episode 划分 `train`、`val`、`test`、`ood`，纹理种子与输入种子也分开，不随机拆分相邻帧到不同集合。训练数据使用一定范围的摩擦系数，以及与摩擦相关的外观家族，因此模型可能学到外观捷径。测试中保留只改变外观、隐藏摩擦变化、电机故障及外观与摩擦映射反转等对照，用于检查这种相关关系失效时的表现。

## 四种模型

| 模型 | 输入与作用 |
|---|---|
| 固定物理基线 | 使用固定的名义动力学模型预测 |
| `historyGRU`（结果键 `history`） | 从近期状态、控制与残差历史学习时间信息 |
| `visionCNN`（结果键 `vision`） | 视觉上下文模型；图像特征与当前运动状态、输入共同用于预测，并非只看图片 |
| `fusionCNNGRU`（结果键 `fusion`） | 结合图像与运动历史，生成 8 维潜在状态并用于预测 |

神经网络权重通过离线训练学习。部署与重放时固定权重，GRU 隐状态随着新观测在线更新；这与每一步重新训练网络不同。潜在状态是学习得到的表示，不等于真实摩擦系数、质量或电机效率，不能把某个潜在维度直接解释为物理参数。

## 预测时序与公平比较

同时评估一步 0.1 秒预测和 0.5 秒多步预测。预测起点只使用当前已获得的图像、观测和历史；多步展开冻结起点潜在状态，不读取未来观测或未来 RGB。未来真值只用于评分，不能用于更新该次预测。

未来输入来自预先生成的命令序列，在预测起点已知。训练目标使用带噪观测，归一化只拟合训练集，权重选择只使用验证集。正式指标跳过最初 1 秒冷启动，在相同有效起点上计算速度和角速度的合并 RMSE；相邻多步预测会重叠，不能把所有起点当作独立重复实验。

先查看独立测试集，再查看分布外对照。应分别报告线速度与角速度误差、单步与多步误差，保留视觉没有改善或导致退化的场景。只换外观不应自动等同于摩擦变化；电机故障也不能仅靠地面图像确认。训练损失下降不等于独立测试或真实机器人性能已经提高。

## 实际训练与测试结果

三个模型都已在 CPU 上实际训练 40 个 epoch，训练种子为 0。按验证损失选择的最佳 epoch 分别为历史模型 40、视觉上下文模型 39、融合模型 40。这是一次训练种子的有限模拟实验，没有重复训练置信区间。

12 个独立测试 episode 的 0.5 秒预测结果如下，完整精度及单步指标见 `results/trained/metrics.json`：

| 模型或消融 | 速度 RMSE（米/秒）↓ | 角速度 RMSE（弧度/秒）↓ |
|---|---:|---:|
| 固定物理基线 | 0.03065 | 0.06280 |
| 历史 GRU | 0.01181 | 0.02003 |
| 视觉上下文 CNN | 0.01383 | 0.03261 |
| 融合 CNN-GRU | 0.01139 | 0.01964 |
| 融合模型重置历史状态 | 0.02487 | 0.04263 |
| 融合模型替换为无关图像 | 0.01139 | 0.01964 |

融合模型略优于历史模型，但替换图像后结果几乎不变，重置历史状态则明显退化，支持当前模型主要依赖运动历史。这里重置的是每个起点的 GRU 隐状态，仍保留当前运动状态、上一输入和一步残差，因此不是完全无历史。图像替换使用训练集中的无关 RGB，不使用未来测试图像；它同时破坏语义对应与连续性，只作为敏感性检查，不能单凭它证明图像完全没有信息。

在 12 个分布外 episode 上，融合模型速度 RMSE 为 0.02760，高于历史模型的 0.02392；角速度 RMSE 为 0.06861，略低于历史模型的 0.07014。视觉增益尚未确立，不能为了得到视觉获胜的结论忽略这些退化。

## 已完成的流式与数据检查

`verify_pipeline.py` 已通过：84 份数据的哈希与种子划分检查、改变未来观测和图像不影响共享前缀预测、流式与批处理因果推理一致、新 MuJoCo 运行中的运动与预测复现。另一次完整无窗口演示运行 120 步，权重哈希前后不变，8 维潜在状态随观测变化；其模型推理中位耗时约 2.4 毫秒。这不包括完整物理步、相机渲染和界面等系统开销，不能当作整套系统延迟。演示指标包含冷启动，不能直接替代正式测试指标。

相机与地面对应检查使用六个合成姿态、共 12 个轮地投影点；独立渲染分割 ID 与预期地面一致。`alignment_error_m` 只是投影与反投影的代数往返误差，不是真实相机标定精度。相机仍是隐藏机器人几何体的当前接触下视相机，未实现前视图像到未来接触位置的时空映射。

这是有限模拟数据下的初步学习实验，不代表真实地面材料识别或实物动力学适应已经完成。需要增加独立场景、纹理、输入和重复训练，再用真实标注数据与机器人实验验证；当前不能保证加入视觉始终优于仅使用运动历史。
