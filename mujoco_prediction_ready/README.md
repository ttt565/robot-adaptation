# MuJoCo 同日志运动预测对照

本页路径相对于仓库根目录。命令示例从仓库根目录的 CMD 开始；第一次 cd 进入本阶段目录。依赖安装见[仓库说明](../README.md)。

这个实验专门比较运动预测，不使用限速或轨迹跟踪控制器。机器人执行预定的左右轮输入，真实 MuJoCo 对每个场景、种子只采集一次，四种预测器随后重放同一份日志。这样各方法使用相同运动、输入和观测噪声，预测差异不会混入“某组减速更多”的影响。

## 运行

打开 `mujoco_prediction_ready`，双击 `run_prediction.cmd`。默认依次执行五个场景、种子 2 和 3，采集数据并完成预测对照。启动器优先使用上一级目录的 `.venv\Scripts\python.exe`，找不到时使用命令行中的 `python`；不会自动安装软件。

在已经激活原虚拟环境的 CMD 中也可运行：

```cmd
cd /d mujoco_prediction_ready
python run_prediction.py --all-cases --seeds 2 3
```

仅采集数据：

```cmd
python run_prediction.py --collect-only --all-cases --seeds 2 3 --output-dir results_test
```

对已经采集的同一目录重新评分：

```cmd
python run_prediction.py --replay-only --all-cases --seeds 2 3 --output-dir results_test
```

`--replay-only` 必须指向包含所选场景、种子日志的已有输出目录。单独选择场景可使用 `--case normal`、`visible_surface_only`、`hidden_low_friction`、`visible_low_friction` 或 `motor_fault`。全部参数请运行 `python run_prediction.py --help`。

实验不打开交互窗口，但采集相机图像仍需要离屏 OpenGL 渲染。采集和重放可能慢于实际时间；请以终端输出为准。

## 四种预测器

| 方法 | 使用的信息 |
|---|---|
| `fixed` | 正常工况离线标定的固定模型 |
| `history_long` | 最近 160 步，即 3.2 秒运动历史 |
| `history_adaptive` | 根据运动线索在 40～160 步之间调整窗口 |
| `vision_history` | 在相同自适应历史方法上，额外使用 RGB 外观变化触发短窗口 |

视觉触发只改变窗口调度，不清空已有历史。它不是图像到摩擦系数的学习模型。四种方法的在线状态仍是左右有效效率 `z = [eta_left, eta_right]`，不能把估计值当作真实摩擦系数。

## 预测和评分规则

同时评估 0.02 秒一步预测与 0.5 秒、25 步预测。多步预测在起点冻结当前参数，只根据当前可用观测和已知的未来预定输入向前计算，不读取起点之后的观测或图像。未来输入已知，是因为本实验事先规定了完整命令序列。

评分使用真实未来线速度、角速度；真值只用于评分，不提供给预测器。图像也按采集时间进入重放，不能提前使用尚未拍摄的图像。每个方法在同一日志的相同有效起点上比较，避免因预测区间不同而改变结果。

优先查看各场景的一步与多步误差，以及扰动前后误差随时间的变化。只换外观时，视觉触发可能没有帮助，甚至引入额外波动；隐藏低摩擦和电机故障也可能没有视觉线索。低摩擦下，简单有效效率模型可能不足以表示真实运动，应保留负结果，不能预先保证视觉方法获胜。

## 输出

数据目录 `datasets` 保存机器人日志 `.npz`、相机识别 CSV 和首末 RGB 图像；预测目录保存各模式的预测 `.npz` 与指标 JSON。根目录生成 `prediction_dashboard.png` 和 `report.json`。具体路径以终端输出为准。

保留原始日志，后续修改预测器时可以使用 `--replay-only` 在相同数据上重新比较，无需重新运行物理仿真。结果只说明这些预定输入与模拟场景下的预测表现，不直接证明闭环控制性能改善，也不代表已实现真实道路材料识别。

## 已验证结果与解释

种子 2、3 分别执行五个场景，共采集 10 份 MuJoCo 日志，再用四种方法得到 40 组同日志预测。这不是 40 次独立物理试验，也不足以代表稳健统计结论。以下数值是两个种子各自指标的平均；实验时长为 16 秒，评分前有 3.2 秒历史准备期。

电机输出异常后的 0.5 秒预测结果为：

| 方法 | 速度预测 RMSE（米/秒）↓ | 角速度预测 RMSE（弧度/秒）↓ | 误差达标确认延迟（秒）↓ |
|---|---:|---:|---:|
| `fixed` | 0.04564 | 0.20823 | 两次均未确认达标 |
| `history_long` | 0.01934 | 0.07509 | 4.31 |
| `history_adaptive` | 0.01562 | 0.05082 | 2.87 |
| `vision_history` | 0.01562 | 0.05082 | 2.87 |

运动历史更新改善了此处的多步预测；自适应窗口的确认延迟低于长窗口。电机故障时没有地面外观变化，视觉方法与相同的历史自适应方法重合，没有额外视觉收益。

低摩擦后的 0.5 秒预测也表现出更新作用。固定模型的两种子平均速度、角速度 RMSE 为 0.07620、0.04987；历史自适应方法为 0.02352、0.03741，相应误差达标确认延迟为 2.66 秒，固定模型两次均未确认达标。这些改善表示有效模型适应，不能解释为已经恢复真实摩擦系数。

视觉的额外作用不稳定。可见低摩擦场景中，种子 2 的视觉方法速度和角速度误差均高于历史自适应方法；种子 3 的速度误差略低，但角速度误差更高。健康工况下，固定模型略好：平均速度、角速度 RMSE 为 0.00745、0.00158，历史更新方法约为 0.00897、0.00271。在线更新也会引入噪声代价，不能只挑故障后的改善报告。

### “确认延迟”如何计算

预先固定的达标条件是：0.5 秒预测的速度误差 RMSE 不超过 0.03 米/秒、角速度误差 RMSE 不超过 0.06 弧度/秒。每次计算最近 50 个预测起点的 RMSE，再要求连续 50 次检查通过；最后还要等 0.5 秒预测目标的真实状态可用。因此该评价在理想情况下也有约 2.46 秒的最早确认时间，不能把确认延迟当作模型真实最短适应耗时。

扰动后指标只使用预测起点不早于事件时刻的样本，未完成的末尾多步目标不纳入评分。图中事件前约半秒的多步误差可能已经上升，因为该次预测跨过了后来实际发生的事件；这是事后使用未来真值评价的结果，不是预测器提前知道事件。在线状态 `z` 始终表示有效左右驱动效率，不是真实摩擦系数。
